6.14.1. type locale¶

`locale` is a set of parameters that defines the language, the region, etc. A `locale` is used for software internationalization.

6.14.1.1. Locale.lang_tag¶

`lang_tag` returns a `str` of the language tag of the locale.

The result is a syntactically well-formed IETF BCP47 language tag. It is not guaranteed that subtags are registered in IANA Language Subtag Registry.

6.14.1.2. Locale.group_sep¶

`group_sep` returns a `str` which separates groups of digits within the integral part of numbers.

6.14.1.3. Locale.decimal_sep¶

`decimal_sep` returns a `str` which separates the integral part and the fractional part of numbers.

6.14.1.4. L1 == L2¶

`==` operator, or `op_eq` method, returns whether two locales `L1` and `L2` have the equal language tag.

Precondition

`L2` must be a `locale`.

6.14.2. LOCALE.for(Lang_tag)¶

`for` returns a `locale` which best matches the given language tag.

Precondition

`Lang_tag` must be a `str`.

6.14.3. LOCALE.is?(Val)¶

`is?` returns whether `Val` is a `locale`.

6.14.4. LOCALE.root¶

`root` is a constant of the empty `locale` which is neutral to any language or region.

6.14.5. LOCALE.default¶

`default` returns the `locale` which is default for the runtime.
