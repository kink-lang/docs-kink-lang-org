type bin
========

\`bin\` is a finite length immutable byte array.

Elements of \`bin\` are integer \`num\` values in the range \[0x00, 0xff\]\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    :Magic <- BIN.of(0xca 0xfe 0xba 0xbe)
    :Slice <- Magic.take_front(2)
    stdout.print_line(Slice.repr) # => (bin 0xca 0xfe)

--------

Bin.any?
--------

\`any?\` returns whether the size of \`Bin\` is greater than or equal to 1.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    stdout.print_line(BIN.of().any?.repr)     # => false
    stdout.print_line(BIN.of(0x00).any?.repr) # => true

Bin.get\(Ind\)
--------------

\`get\` returns the element at the index \`Ind\` in \`Bin\`\.

The result is an integer \`num\` in the range \[0x00, 0xff\]\.

.. rubric:: Precondition

\`Ind\` must be an integer \`num\` in the range \[0, Bin.size\)\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    :Magic <- BIN.of(0xca 0xfe 0xba 0xbe)
    stdout.print_line(Magic.get(1).repr) # => 254

Bin.slice\(From To\)
--------------------

\`slice\` returns a \`bin\` of the slice in the range \[From, To\)\.

.. rubric:: Preconditions

\`From\` and \`To\` must be integer \`num\` values.

0 \<\= From \<\= To \<\= Bin.size

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    :Magic <- BIN.of(0xca 0xfe 0xba 0xbe)
    :Slice <- Magic.slice(1 3)
    stdout.print_line(Slice.repr) # => (bin 0xfe 0xba)

Bin1 \+ Bin2
------------

\`\+\` operator, or \`op_add\` method, returns a \`bin\` containing the elements of \`Bin1\` on the front, and the elements of \`Bin2\` on the back.

.. rubric:: Precondition

\`Bin2\` must be a \`bin\`\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
    :Cafe <- BIN.of(0xca 0xfe)
    :Babe <- BIN.of(0xba 0xbe)
    :Cafe_babe <- Cafe + Babe
    stdout.print_line(Cafe_babe.repr) # => (bin 0xca 0xfe 0xba 0xbe)

Bin \* N
--------

\`\*\` operator, or \`op_mul\` method, returns a \`bin\` repeating the elements of \`Bin\`\, \`N\` times.

.. rubric:: Precondition

\`N\` must be a non\-negative integer \`num\`\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
    :Babe <- BIN.of(0xba 0xbe)
    :Babe_babe_babe <- Babe * 3
    stdout.print_line(Babe_babe_babe.repr) # => (bin 0xba 0xbe 0xba 0xbe 0xba 0xbe)

Bin1 \=\= Bin2
--------------

\`\=\=\` operator, or \`op_eq\` method, returns whether \`Bin1\` and \`Bin2\` contain the same sequence of elements.

.. rubric:: Precondition

\`Bin2\` must be a \`bin\` value.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
    :Bin <- BIN.of(1 2 3)
        
    stdout.print_line((Bin == BIN.of(1 2 3)).repr)  # => true
    stdout.print_line((Bin != BIN.of(1 2 3)).repr)  # => false
        
    stdout.print_line((Bin == BIN.of(3 2 1)).repr)  # => false
    stdout.print_line((Bin != BIN.of(3 2 1)).repr)  # => true

Bin1 \<\= Bin2
--------------

\`\<\=\` operator, or \`op_le\` method, returns whether \`Bin1\` is smaller than or equal to \`Bin2\` lexicographically.

.. rubric:: Precondition

\`Bin2\` must be a \`bin\` value.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    :compare <- {(:Bin :Arg_bin)
      [:Lt? :Le? :Gt? :Ge?] = [
        Bin < Arg_bin
        Bin <= Arg_bin
        Bin > Arg_bin
        Bin >= Arg_bin
      ]
      stdout.print_line(
        'Lt?={} Le?={} Gt?={} Ge?={}'.format(Lt?.repr Le?.repr Gt?.repr Ge?.repr))
    }
        
    compare(BIN.of(1 2 3) BIN.of(1 2 3))    # => Lt?=false Le?=true Gt?=false Ge?=true
    compare(BIN.of(1 2 3) BIN.of(1 2 3 4))  # => Lt?=true Le?=true Gt?=false Ge?=false
    compare(BIN.of(1 2 3) BIN.of(1 2))      # => Lt?=false Le?=false Gt?=true Ge?=true

Bin.repr
--------

\`repr\` returns a \`str\` representation of \`Bin\`\.

The representation contains the elements as hexadecimal numbers, like \`\(bin 0x00 0x01 0xfe 0xff\)\`\.

If the size of \`Bin\` is greater than 128, the representation is abbreviated by the first and the last 32 elements, with the total size between them.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    stdout.print_line(BIN.of(0 1 254 255).repr) # => (bin 0x00 0x01 0xfe 0xff)

BIN.from_each\(Eacher\)
=======================

\`from_each\` returns a \`bin\` containing the elements of \`Eacher\`\.

.. rubric:: Preconditions

\`Eacher\` must support the \`\.each\($consume\)\` method, like vectors and iters.

Each element of \`Eacher\` must be an integer \`num\` in the range \[0x00, 0xff\]\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BIN.require_from('kink/')
        
    :Bin <- BIN.from_each([0 1 254 255])
    stdout.print_line(Bin.repr) # => (bin 0x00 0x01 0xfe 0xff)
