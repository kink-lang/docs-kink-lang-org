RUNTIME.major_version
=====================

\`major_version\` returns the major version of the runtime in an integer \`num\`\.

Versioning scheme of Kink follows Semantic Versioning 2.0.0. See\:

https\:\/\/semver.org\/

RUNTIME.windows?
================

\`windows?\` returns whether the runtime is drectly running on a Windows system.

The assumption is that if the runtime is running on Windows, it is not on Unix, and vice versa. Thus, only one of \`windows?\` and \`unix?\` returns true.

.. _api-ffa01e6b6ca8b9566ae75de2a966c573:

RUNTIME.unix?
=============

\`unix?\` returns whether the runtime is drectly running on a Unix\-like system.

The assumption is that if the runtime is running on Windows, it is not on Unix, and vice versa. Thus, only one of \`windows?\` and \`unix?\` returns true.
