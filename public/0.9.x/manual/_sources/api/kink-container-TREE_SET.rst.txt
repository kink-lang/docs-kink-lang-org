==========================
kink\/container\/TREE\_SET
==========================

Provides an \`order\_set\` implementation which stores all the elements in a balanced binary tree\.

Tree set is a safe default choice\, because it guarantees logarithmic worst\-case computational complexity for operations like \.push and \.have\?\.

.. contents::
    :local:
    :backlinks: none

.. _api-0dffcb8842ed6c355c0d35e82bc13e7e:

TREE\_SET\.new\(\.\.\.\[\$config\=\{\}\]\)
==========================================

\`new\` returns a new empty tree \`order\_set\`\.

.. rubric:: Config method

C\.order\(\$up\_to\?\)\: default \= \{\(\:X \:Y\) X \<\= Y \}

.. rubric:: Total order relation

\$up\_to\? must be a function which takes two args X and Y\. \`up\_to\?\(X Y\)\` must return the bool value of \`X up\-to Y\`\, where \`up\-to\` is the total order relation of elements\.

.. rubric:: Precondition

\$up\_to\? must be a function which takes two values and returns a \`bool\`\.

.. rubric:: Example\: default order

.. code:: kink

    :TREE_SET.require_from('kink/container/')
        
    :Map <- TREE_SET.new
    Map.push('foo')
    Map.push('bar')
    Map.push('baz')
    stdout.print_line(Map.have?('foo').repr) # => true
    stdout.print_line(Map.have?('FOO').repr) # => false
    Map.each{(:Elem)
      stdout.print_line(Elem.repr)
    }
    # Output:
    #   "bar"
    #   "baz"
    #   "foo"

.. rubric:: Example\: reversed order

.. code:: kink

    :TREE_SET.require_from('kink/container/')
        
    :Map <- TREE_SET.new{(:C)
      C.order{(:X :Y) X >= Y }
    }
    Map.push('foo')
    Map.push('bar')
    Map.push('baz')
    Map.each{(:Elem)
      stdout.print_line(Elem.repr)
    }
    # Output:
    #   "foo"
    #   "baz"
    #   "bar"

TREE\_SET\.of\(\.\.\.Elems\)
============================

\`of\` makes a new tree \`order\_set\` which contains the values of \`Elems\`\. The elements of are ordered by \`\<\=\` operator\, or \`op\_le\` method\.

.. rubric:: Precondition

The elements of \`Elems\` must be in the domain of the elements of the set\.

.. rubric:: Example

.. code:: kink

    :TREE_SET.require_from('kink/container/')
        
    :Map <- TREE_SET.of('foo' 'bar' 'baz')
    stdout.print_line(Map.have?('foo').repr) # => true
    stdout.print_line(Map.have?('FOO').repr) # => false
    Map.each{(:Elem)
      stdout.print_line(Elem.repr)
    }
    # Output:
    #   "bar"
    #   "baz"
    #   "foo"

TREE\_SET\.from\_each\(Eacher\)
===============================

\`from\_each\` makes a new empty tree \`order\_set\` containing the elements of \`Eacher\`\. The elements are ordered by \`\<\=\` operator\, or \`op\_le\` method\.

.. rubric:: Precondition

\`Eacher\` must implement each\(\$consume\) method\, which calls \$consume for each element of \`Eacher\`\.

The elements of \`Eacher\` must be in the domain of the elements of the set\.

.. rubric:: Example

.. code:: kink

    :TREE_SET.require_from('kink/container/')
        
    :Iter <- ['foo' 'bar' 'baz'].iter
    :Map <- TREE_SET.from_each(Iter)
    stdout.print_line(Map.have?('foo').repr) # => true
    stdout.print_line(Map.have?('FOO').repr) # => false
    Map.each{(:Elem)
      stdout.print_line(Elem.repr)
    }
    # Output:
    #   "bar"
    #   "baz"
    #   "foo"
