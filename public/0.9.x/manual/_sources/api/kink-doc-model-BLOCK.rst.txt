type block
==========

\`block\` is a block in a kinkdoc document.

A \`block\` has the following attributes\:

\• Type\: a \`block_type\` which corresponds to \"type\" property in JSON data

\• Text\: a \`str\` which corresponds to \"text\" property in JSON data

.. _api-51283f777897decab1f7eeabd642f013:

Block.type
----------

\`type\` method returns \`Type\` attribute of \`Block\`\.

.. _api-373399257a68d0434305ac53476b4654:

Block.text
----------

\`text\` returns \`Text\` attribute of \`Block\`\.

.. _api-a2685142858e5e776e66e15ee1d0072c:

Block.to_json_val
-----------------

\`to_json_val\` converts \`Block\` to a JSON value.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :BLOCK.require_from('kink/doc/model/')
    :BLOCK_TYPE.require_from('kink/doc/model/')
        
    :Para <- BLOCK.new(BLOCK_TYPE.paragraph 'hey!')
    stdout.print_line(Para.to_json_val.repr)
    # => Flat_map("text" "hey!"; "type" "paragraph")
        
    :Code <- BLOCK.new(BLOCK_TYPE.code "1 + 2\n")
    stdout.print_line(Code.to_json_val.repr)
    # => Flat_map("text" "1 + 2\n"; "type" "code")

.. _api-6684b832a43d26078d9d3dce1accfe56:

X \=\= Y
--------

Two \`block\` values are equal when they have equal \`Type\` attributes and \`Text\` attributes.

.. rubric:: Precondition

\`Y\` must be a \`block\`\.

.. _api-b218008aa5d51547dacb4daf4e4e0a36:

BLOCK.new\(Type Text\)
======================

\`new\` returns a new \`block\` value with attributes \`Type\` and \`Text\`\.

.. rubric:: Preconditions

\`Type\` must be a \`block_type\`\.

\`Text\` must be a \`str\`\.

\`Type.valid_text?\(Text\)\` must be true.

.. _api-97d330a2e5b386b1db3899fb2d5af37a:

BLOCK.is?\(Val\)
================

\`is?\` returns whether \`Val\` is a \`block\`\.
