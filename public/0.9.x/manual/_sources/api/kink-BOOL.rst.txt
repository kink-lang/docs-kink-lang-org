type bool
=========

\`bool\` values are \`true\` and \`false\`\.

See Binding.if and Binding.branch for conditional branches.

See \`\!\` \/ Binding.op_lognot, \`\|\|\` \/ Binding.op_logor, \`\&\&\` \/ Binding.op_logand for logical operations.

.. _api-adee8c787898dbbfad047403dfda530e:

Bin1 \=\= Bin2
--------------

\`\=\=\` operator, or \`op_eq\` method, returns whether two \`bool\` values are the same values.

.. rubric:: Precondition

Bin2 must be a \`bool\`\.

.. _api-720ddc3162ac38219e5bf4db24f92857:

BOOL.is?\(Val\)
===============

\`is?\` returns whether \`Val\` is a \`bool\`\.
