6.5.1. bool型¶

bool値はtrueかfalseである。

条件分岐についてはBinding.ifとBinding.branchを見よう。

論理演算については `!` / Binding.op_lognot, `||` / Binding.op_logor, `&&` / Binding.op_logand を見よう。

6.5.1.1. Bin1 == Bin2¶

`==` 演算子、つまりop_eqメソッドは、ふたつのbool値が同じ値かどうかを戻す。

事前条件

Bin2はboolでなければならない。

6.5.2. BOOL.is?(Val)¶

is?は、Valがboolかどうかを戻す。
