6.12.1. fun型¶

funは関数である。

funは、不変で有限長の抽象命令の列を持っていると見なされる。抽象命令の列については、「言語仕様」 → 「評価」の章を見よう。

6.12.1.1. Fun.call(Recv Args)¶

callは、Recvを呼び出しのレシーバとして、Argsを引数ベクタとして、Funを末尾呼び出しする。

callの末尾では、次の抽象命令列が評価される:

(val Fun)
(val Recv)
(val Args)
(tailcall)

事前条件

Argsはvecでなければならない。

6.12.2. FUN.is?(Val)¶

is?は、Valがfunであるかどうかを戻す。
