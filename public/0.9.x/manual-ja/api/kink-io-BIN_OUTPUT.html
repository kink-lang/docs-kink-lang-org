6.57.1. BIN_OUTPUT.new¶

new は bin を構築する output を戻す。

結果のoutputはbinメソッドも提供する。これはwriteメソッドに渡されたバイト列を結合したbin値を戻す。

flush

flushメソッドは何もしない。outputが閉じられていなければ、単に$successを末尾呼び出しする。

close

outputが閉じられたら、writeメソッドとflushメソッドはIOエラーを生じる。これは、システムリソースを元にするoutputの実装と同じである。

例

:BIN_OUTPUT.require_from('kink/io/')
:BIN.require_from('kink/')
:CONTROL.require_from('kink/')

:make_bin <- {
  CONTROL.with_finally{(:finally)
    :Out = BIN_OUTPUT.new
    finally{ Out.close }
    Out.write(BIN.of(1 2 3))
    Out.write(BIN.of(4))
    Out.bin
  }
}
stdout.print_line(make_bin.repr) # => (bin 0x01 0x02 0x03 0x04)
