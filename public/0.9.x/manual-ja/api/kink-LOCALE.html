6.14.1. locale型¶

localeは、言語、地域などを定義するパラメータの集合である。localeはソフトウェア国際化に使われる。

6.14.1.1. Locale.lang_tag¶

lang_tagはロケールの言語タグのstrを戻す。

結果は文法的に整形式なIETF BCP47言語タグである。サブタグがIANA Language Subtag Registryに登録されていることは保証されない。

6.14.1.2. Locale.group_sep¶

group_sepは、数値の整数部分の桁のグループを区切るstrを戻す。

6.14.1.3. Locale.decimal_sep¶

decimal_sepは、数値の整数部分と小数部分を区切るstrを戻す。

6.14.1.4. L1 == L2¶

== 演算子、つまりop_eqメソッドは、ふたつのロケールL1とL2が等しい言語タグを持っているかどうかを戻す。

事前条件

L2はlocaleでなければならない。

6.14.2. LOCALE.for(Lang_tag)¶

forは、与えられた言語タグにもっとも良く合致するlocaleを戻す。

事前条件

Lang_tagはstrでなければならない。

6.14.3. LOCALE.is?(Val)¶

is?はValがlocaleであるかどうかを戻す。

6.14.4. LOCALE.root¶

rootは、言語や地域に対して中立的な、空のlocaleの定数である。

6.14.5. LOCALE.default¶

defaultは、ランタイムのデフォルトのlocaleを戻す。
