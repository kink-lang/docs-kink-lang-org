6.21. kink/RUNTIME¶

Kinkのランタイムの情報を提供する。

  • RUNTIME.major_version

  • RUNTIME.minor_version

  • RUNTIME.patch_version

  • RUNTIME.version_str

  • RUNTIME.windows?

  • RUNTIME.unix?

6.21.1. RUNTIME.major_version¶

major_versionは、ランタイムのメジャーバージョンを整数のnumとして戻す。

Kinkのバージョニング方式は、Semantic Versioning 2.0.0に準拠する。参照:

https://semver.org/

6.21.2. RUNTIME.minor_version¶

minor_versionは、ランタイムのマイナーバージョンを整数のnumとして戻す。

Kinkのバージョニング方式は、Semantic Versioning 2.0.0に準拠する。参照:

https://semver.org/

6.21.3. RUNTIME.patch_version¶

patch_versionは、ランタイムのパッチバージョンを整数のnumとして戻す。

Kinkのバージョニング方式は、Semantic Versioning 2.0.0に準拠する。参照:

https://semver.org/

6.21.4. RUNTIME.version_str¶

version_strは、ランタイムのバージョン文字列を、たとえば '1.2.3' のように戻す。

Kinkのバージョニング方式は、Semantic Versioning 2.0.0に準拠する。参照:

https://semver.org/

6.21.5. RUNTIME.windows?¶

windows?は、ランタイムがWindowsシステムの上で直接動作しているかどうかを戻す。

ランタイムは、Windows上で動作していなければ、Unix上で動作しているとして、またその逆として仮定される。したがって、windows?とunix?のどちらかだけがtrueを戻す。

6.21.6. RUNTIME.unix?¶

unix?は、ランタイムがUnixライクのシステム上で直接動作しているかどうかを戻す。

ランタイムは、Windows上で動作していなければ、Unix上で動作しているとして、またその逆として仮定される。したがって、windows?とunix?のどちらかだけがtrueを戻す。
