6.68.1. STR_PRINTER.new(Newline)¶

new は文字列を構築するprinterを戻す。NewlineはPrinter.newlineとして使われる。

結果のprinterはstrメソッドも提供する。これは、printメソッドに渡された文字列、および、print_lineに渡された文字列にnewlineを足したものを連結して戻す。

事前条件

Newline は str 型でなければならない。

例

:STR_PRINTER.require_from('kink/io/')

:P <- STR_PRINTER.new("\r\n")
P.print_line('foo')
P.print_line('bar')
stdout.print_line(P.str.repr) # => "foo\r\nbar\r\n"
