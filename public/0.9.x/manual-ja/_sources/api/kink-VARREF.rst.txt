type varref
===========

\`varref\` is a variable reference, which is a value that represents a variable.

A \`varref\` is a tuple of \(Owner, Sym\)\, where \`Owner\` is the owner value of the variable, and \`Sym\` is the symbol of the variable.

\`varref\` is a subtype of \`plain_param\`\. See kink\/param\/PLAIN_PARAM.

.. _api-9149b04024119e6743bfce567a330250:

Varref.owner
------------

\`owner\` returns \`Owner\` of \`Varref\`\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :Owner <- 42
    :Varref <- Owner:Foo
    stdout.print_line(Varref.owner.repr) # => 42

.. _api-f0bd1a74333e30f4a156fdead5a0aba1:

Varref.sym
----------

\`sym\` returns a \`str\` value of \`Sym\` of \`Varref\`\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :Owner <- 42
    :Varref <- Owner:Foo
    stdout.print_line(Varref.sym.repr) # => "Foo"

Varref \<\- Content
-------------------

\`\<\-\` operator, or \`op_store\` method, performs variable\-store operation for the variable represented by \`Varref\`\, with \`Content\` as the content of the variable.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :V <- 42
    stdout.print_line(V.repr) # => 42

.. _api-ccb05513dd1c65fedbb36887fcd81818:

Varref.load
-----------

\`load\` performs variable\-load operation for the variable represented by \`Varref\`\, and returns the content value of the variable.

.. rubric:: Precondition

The content of the variable must not be empty.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :V <- 42
    stdout.print_line(:V.load.repr) # => 42

.. _api-76b0760cfb86b823ba19b86b27802ba7:

Varref.any?
-----------

\`any?\` performs variable\-load operation for the variable represented by \`Varref\`\, and returns whether the content is not empty.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :Owner <- new_val('Foo' 42)
    stdout.print_line(Owner:Foo.any?.repr)  # => true
    stdout.print_line(Owner:Bar.any?.repr)  # => false

Varref.require_from\(Prefix\)
-----------------------------

\`require_from\` loads a module then stores the module to the variable.

Calling this method is equivalent to calling \`Varref \<\- MOD.require\(Prefix \+ Varref.sym\)\`\.

.. rubric:: Precondition

\`Prefix\` must be a \`str\`\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :NUM.require_from('kink/')
    stdout.print_line(NUM.is?(42).repr)  # => true

.. _api-58a0d84a3d4a63aee83546415f4bd5f5:

Varref.rest
-----------

\`rest\` returns a \`rest_param\` backed by the variable.

\`pass_rest\(Rest_args\)\` method of the result \`rest_param\` stores \`Rest_args\` to the variable.

See also kink\/param\/REST_PARAM

.. rubric:: Example

.. code:: kink
    :class: no-search

    :take_args <- {(:X :Y :Z.rest)
      stdout.print_line(X.repr)
      stdout.print_line(Y.repr)
      stdout.print_line(Z.repr)
    }
        
    take_args('foo' 'bar')
    # Output:
    #   "foo"
    #   "bar"
    #   []
        
    take_args('foo' 'bar' 'baz')
    # Output:
    #   "foo"
    #   "bar"
    #   ["baz"]
        
    take_args('foo' 'bar' 'baz' 'qux')
    # Output:
    #   "foo"
    #   "bar"
    #   ["baz" "qux"]

.. _api-a6b43b4c86defa1c7e8594a542d1c2fa:

Varref.opt
----------

\`opt\` makes an \`opt_param\` backed by the variable.

\`pass_arg\(Arg\)\` method of the result \`opt_param\` stores a singleton vector \`\[Arg\]\` to the variable.

\`pass_nothing\` method of the result opt_param stores an empty vector to the variable.

See also kink\/param\/OPT_PARAM

.. rubric:: Example

.. code:: kink
    :class: no-search

    :take_args <- {(:X :Y :Z.opt :W.opt)
      stdout.print_line(X.repr)
      stdout.print_line(Y.repr)
      stdout.print_line(Z.repr)
      stdout.print_line(W.repr)
    }
        
    take_args('foo' 'bar')
    # Output:
    #   "foo"
    #   "bar"
    #   []
    #   []
        
    take_args('foo' 'bar' 'baz')
    # Output:
    #   "foo"
    #   "bar"
    #   ["baz"]
    #   []
        
    take_args('foo' 'bar' 'baz' 'qux')
    # Output:
    #   "foo"
    #   "bar"
    #   ["baz"]
    #   ["qux"]

VARREF.new\(Owner Sym\)
=======================

\`new\` returns a \`varref\` \(Owner, Sym\)\.

.. rubric:: Precondition

\`Sym\` must be a \`str\`\.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :VARREF.require_from('kink/')
    :Owner <- new_val('Foo' 42)
    :Varref <- VARREF.new(Owner 'Foo')
    stdout.print_line(Varref.load.repr) # => 42
