=========================================
kink\/doc\/render\/html\/HTML_RENDER_TOOL
=========================================

Launcheable module to render a kinkdoc document to a single HTML file.

.. rubric:: Usage

.. code:: kink
    :class: no-search

    kink [Kink_options]... mod:kink/doc/render/html/HTML_RENDER_TOOL [Mod_options] <JSON >HTML

The command reads kinkdoc JSON data from the standard input, converts it to a single HTML file, and writes it to the standard output.

.. rubric:: Mod_options

\• \-\-style \{Style_file_path\} \: gives the file path of a CSS file. The file content must be encoded in UTF\-8. It is inserted in the style element of the HTML file.

\• \-\-template \{Template_file_path\} \: gives the file path of the HTML template file. See the next section for details.

.. rubric:: HTML template content

The HTML template must be encoded in UTF\-8, and be a Str.format template string. It can contain placeholders \`\{Title\}\` for the HTML\-escaped document title, \`\{Style\}\` for the CSS, and \`\{Body\}\` for the content of \<body\> element.

The default template is as follows\:

.. code:: kink
    :class: no-search

    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="utf-8" />
      <title>{Title}</title>
      <style>
    {Style}
      </style>
    </head>
    <body>
    {Body}
    </body>
    </html>

.. rubric:: Exit statuses

If the command succeeds, it exits with 0 as the exit status.

If not, the command exits with a non\-zero exit status.

.. rubric:: Usage example

.. code:: kink
    :class: no-search

    $ kink mod:kink/doc/DOC_PARSE_TOOL --title 'API reference' src >doc.json
    ...
    $ kink mod:kink/doc/render/html/HTML_RENDER_TOOL <doc.json >doc.html
