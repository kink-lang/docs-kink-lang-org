type block\_type
================

\`block\_type\` is an enum type of \`paragraph\`\, \`code\` and \`heading\`\, which represents the type of a block\.

.. _api-5ce34c32333facdfdf3e5122de955a55:

Block\_type\.name
-----------------

\`name\` returns a \`str\` value of \"paragraph\"\, \"code\"\, or \"heading\"\.

.. _api-8f8037ccc5b263a5fd30560d1939f0b2:

Block\_type\.valid\_text\?\(Text\)
----------------------------------

\`valid\_text\?\` returns whether \`Text\` is accepted as the \`text\` property of a block with the block type\.

If the block type is \`paragraph\` or \`heading\`\, \`Text\` is accepted when it matches the regex pattern\:

.. code:: kink

    [^\u0000-\u0020\u007f]( *[^\u0000-\u0020\u007f])*

If the block type is \`code\`\, \`Text\` is accepted when it matches the regex pattern\:

.. code:: kink

    ( *[^\u0000-\u0020\u007f]+( +[^\u0000-\u0020\u007f]+)*\n)(\n?( *[^\u0000-\u0020\u007f]+( +[^\u0000-\u0020\u007f]+)*\n))*

See “Kinkdoc\: API Documentation system” → “Data model” → “JSON Schema” in the manual for the schema\.

.. rubric:: Precondition

\`Text\` must be a \`str\`\.

.. _api-e325e705cfb17ea26e00cbea147820e8:

X \=\= Y
--------

\`X\` and \`Y\` are equal when they are the same \`block\_type\` value\.

.. rubric:: Precondition

\`Y\` must be a \`block\_type\`\.
