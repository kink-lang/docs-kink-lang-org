type enum_group
===============

An \`enum_group\` is a generator of a set of enum values.

.. rubric:: Example

.. code:: kink
    :class: no-search

    :ENUM_GROUP.require_from('kink/')
        
    :Eg <- ENUM_GROUP.new('FILE_TYPE')
        
    Eg.register(:file)
    Eg.register(:directory)
    Eg.register(:symbolic_link)
        
    stdout.print_line(file.repr)  # => FILE_TYPE.file
        
    stdout.print_line((file == file).repr)      # => true
    stdout.print_line((file == directory).repr) # => false

Enum_group.new_member\(Name\)
-----------------------------

\`new_member\` returns a new enum value of the enum group. \`Name\` is used as the name of the enum value.

The result enum value provides the following method\:

\• M1 \=\= M2\: returns whether \`M1\` and \`M2\` are the same enum value. Precondition\: \`M1\` and \`M2\` must belong to the same enum group.

.. rubric:: Precondition

\`Name\` must be a \`str\`\.

.. _api-435f62220362afd78bd05939fb766851:

Enum_group.register\(Varref\)
-----------------------------

\`register\` makes a new enum value using \`new_member\` method, and sets a constant of the enum value to \`Varref\`\. The symbol of \`Varref\` is used as the name of the enum value.

.. rubric:: Precondition

\`Varref\` must be a \`varref\`\.

.. _api-bd974959328220875cfcf53265d01a7d:

Enum_group.name
---------------

\`name\` returns the \`str\` value of the name of the enum group.

.. _api-62607da2bd5113ff080fa2d99b50a022:

Enum_group.all
--------------

\`all\` returns a \`vec\` of all the enum values of the enum group, in the order that the members were created.

.. _api-dd3fb1341be629eeadd81cc3eed414c0:

Enum_group.have?\(Val\)
-----------------------

\`have?\` returns whether \`Val\` belongs to the enum group.

.. _api-1f683b942e1437f94bb0b639d357b83b:

ENUM_GROUP.new\(Name\)
======================

\`new\` makes a new \`enum_group\`\.

\`Name\` is used as the name of the enum group.

.. rubric:: Precondition

\`Name\` must be a \`str\`\.
